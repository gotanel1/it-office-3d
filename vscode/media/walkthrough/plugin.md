## Why a plugin?

IT-Office-3D only draws the office. A small **Claude Code plugin** reports what Claude is doing, through Claude Code's hooks, to a server on your own computer.

The button runs these two commands in a new terminal:

```
claude plugin marketplace add gotanel1/it-office-3d
claude plugin install it-office-3d@it-office-3d
```

Then run **Reload Window** so Claude Code picks the plugin up. Nothing leaves your computer: no account, no key, no telemetry.
